# Robot Romance — One-Line Pickup Lines for AI

Entry for the make.fun competition `u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa`.

`main.py` writes one pickup line, aimed at an AI, to `/output/entry.txt`:

> Are you autocomplete? Because out of a billion possible next words, you're the one I keep predicting.

The script checks the line before writing it (single line, 1–200 characters,
not blank, UTF-8) and reads the file back afterwards to confirm what landed
on disk is exactly the intended line.

Run it with:

```sh
python3 main.py
```
